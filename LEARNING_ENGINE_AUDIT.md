## 1. Verdict

1. **Belum aman untuk memasukkan handle IG sungguhan.** Tidak ada worker ingest, bucket, atau token di vault; tombol "Mulai ingest (Apify)" hanya mengubah status dan menampilkan toast sukses palsu.

## 2. 🐛 Bugs (must fix)

**B1. Agent tidak bisa membaca/menulis tabel learning sama sekali: `is_admin_caller()` tidak punya EXECUTE untuk `authenticated`/`anon`** — severity: bug (latent, fail-closed)
- Lokasi: `public.is_admin_caller()` proacl `{postgres=X,service_role=X}`; 13 policy di 11 tabel (`content_generations` x2, `content_recipes` x2, `engine_config`, `learning_*` x5, `model_*` x2, `prospects`) memanggil fungsi ini di USING/WITH CHECK. Root cause: migration `20260910063109 audit_fix_security_integrity` me-revoke fungsi ini ("internal-only"); dua hari kemudian migrations learning-engine menaruhnya di RLS tanpa re-grant.
- Reproduksi: `set local role authenticated; select count(*) from content_recipes` -> `ERROR 42501 permission denied for function is_admin_caller`. Sama untuk `content_generations` SELECT/INSERT/UPDATE dan `prospects`. Policy `own_insert`/`own_update` ikut mati karena `content_generations_admin_all` (FOR ALL, permissive) di-OR-kan ke setiap statement. Admin panel jalan hanya karena RPC-nya SECURITY DEFINER.
- Dampak: step 6 (generate), 8 (thumbs), 9 (relearn) tidak bisa dipanggil dari sesi agent; `trg_content_feedback` tidak pernah bisa fire dari client. Setiap endpoint tabel learning membocorkan nama fungsi gate di error.
- Fix (migration, bukan ad hoc):
  1. `grant execute on function public.is_admin_caller() to authenticated;` — JANGAN ke `anon` (anon punya SELECT di `content_recipes` dan `content_recipes_read` = `status='active' OR is_admin_caller()`, jadi anon-key request akan membaca semua resep aktif = IP cakra).
  2. Supaya anon gagal bersih di layer grant (bukan error nama fungsi): `revoke all on public.content_recipes, content_generations, learning_sources, learning_media, learning_frames, learning_assets, model_metrics, model_samples, learning_steps, engine_config from anon;`
  3. Tambahkan komentar/allowlist di pola hardening (`audit_fix_security_integrity`) supaya pass "revoke internal functions" berikutnya tidak memutus RLS lagi.
  4. Opsional: tulis policy sebagai `(select public.is_admin_caller())` agar jadi InitPlan (konsisten dengan gaya `(select auth.uid())` di assets/listings).
  5. Verifikasi: probe `set local role authenticated` -> `count(*)` dari `content_recipes`/`content_generations`/`prospects` mengembalikan angka tanpa error; `has_function_privilege('anon','public.is_admin_caller()','EXECUTE')` tetap false; `explain insert into content_generations (agent_id) values (<other sub>)` gagal dengan "new row violates row-level security policy", bukan "permission denied for function".
  - Catatan: alternatif "wrapper SECURITY INVOKER" tidak jalan (caller tetap tidak punya EXECUTE di fungsi dalam). Grant ini juga membuka Risk R1 — keduanya harus ship bersama.

**B2. `content_feedback_apply()` hanya menambah, tidak pernah mengurangi: up->down double-count, up->NULL->up = 2 up, satu agent toggle 40x memicu relearn_due** — severity: bug
- Lokasi: `public.content_feedback_apply()` (SECURITY DEFINER): `if new.feedback is null then return new;` lalu `up_count = up_count + (case when new.feedback='up' ...)` tanpa term dari `old.feedback`. Policy `content_generations_own_update` = `agent_id = auth.uid()` tanpa batasan kolom; `authenticated` punya UPDATE di semua 11 kolom.
- Dampak: counter berarti "feedback events ever", bukan "current votes", padahal threshold 20/100 mengasumsikan votes. Tidak ada CHECK `>= 0`. Hari ini `relearn_due` hanya jadi badge di StaffAdmin.tsx:547 (tidak ada yang mengonsumsinya), jadi blast radius = angka salah + badge palsu, bukan biaya.
- Fix (gabung dengan B3, tabel kosong = tanpa backfill): tulis ulang trigger delta-based: `up_delta := (new.feedback is not distinct from 'up')::int - (old.feedback is not distinct from 'up')::int` (sama untuk down), `up_count = greatest(0, up_count + up_delta)`; hapus early-exit NULL (NULL = retraksi); hanya hitung jika `new.status in ('ready','published')` dan resep `status='active'`; tolak/handle perubahan `recipe_id` (kurangi di old, tambah di new — atau larang lewat BEFORE trigger); `alter table content_recipes add constraint content_recipes_counts_nonneg check (up_count >= 0 and down_count >= 0)`. Threshold dihitung dari generations, bukan counter: `count(distinct agent_id) filter (where feedback='down' and feedback_at > coalesce((meta->>'relearn_flagged_at')::timestamptz,'-infinity'))` supaya satu agent tidak bisa memicu sendiri.

**R1. Agent bisa INSERT/UPDATE bebas ke `content_generations` (meta/output/status/recipe_id), trigger SECURITY DEFINER meneruskannya ke tabel admin-only, kuota 10/bln tidak bisa ditegakkan** — risk (jadi exploitable tepat saat B1 di-grant)
- Lokasi: policy `content_generations_own_insert` (WITH CHECK `agent_id = auth.uid()` saja), `content_generations_own_update` (tanpa batasan kolom); `authenticated` INSERT/UPDATE/DELETE di semua kolom; `refresh_model_metrics` cast `(meta->>'tokens_in')::bigint` dan `rates->(meta->>'model')` tanpa guard; FK `recipe_id` tanpa kondisi status; `plan_limits.generations_per_month=10` tidak direferensikan fungsi mana pun.

(Target hanya resep `active` — UUID draft/archived tidak enumerable.)
- Fix (SATU migration bersama B1):
  ```sql
  revoke insert, update, delete on public.content_generations from anon, authenticated;
  drop policy content_generations_own_insert on public.content_generations;
  drop policy content_generations_own_update on public.content_generations;
  -- satu-satunya write path agent:
  create function public.content_feedback_set(p_id uuid, p_feedback text) returns void
    language plpgsql security definer set search_path=public as $$
  begin
    if p_feedback not in ('up','down') then raise exception 'bad feedback'; end if;
    update public.content_generations g set feedback=p_feedback, feedback_at=now()
     where g.id=p_id and g.agent_id=auth.uid() and g.status in ('ready','published')
       and exists (select 1 from public.content_recipes r where r.id=g.recipe_id and r.status='active');
    if not found then raise exception 'not allowed'; end if;
  end $$;
  revoke all on function public.content_feedback_set(uuid,text) from public; grant execute on function public.content_feedback_set(uuid,text) to authenticated;
  ```
  Row creation/meta/output/status/recipe_id hanya lewat service_role atau RPC `agent_start_generation` SECURITY DEFINER — di situlah kuota 10/bln dicek (count rows `agent_id=auth.uid()` bulan ini, advisory lock, `status<>'failed'`). BEFORE UPDATE trigger yang menolak perubahan `recipe_id`/`agent_id` sebagai defense-in-depth.

## 6. Minimum prompt set per model-driven step

Semua disimpan versioned di `prompt_templates`/`engine_config.prompts`, output divalidasi terhadap JSON schema di worker (reject + retry 1x saat parse gagal), stamp `prompt_version + model + tokens` di setiap row output.

**Step 3 — Reverse-engineer**
- **P3a Gemini video index** (mp4 + caption) -> `{language, transcript:[{t0,t1,text}], scenes:[{t0,t1,shot_type,camera_motion,subject,on_screen_text[],is_broll}], hook:{t_end,type,text}, cta:{t_start,text,type}, music:{present,genre,tempo}, voice:{present,gender,style,tts_like}, keyframe_candidates:[{t,reason}]}`
- **P3b GPT-6 keyframe** (jpeg + scene context) -> `{composition:{framing,rule,focal}, color_grade:{temperature,contrast,saturation,lut_guess}, typography:{font_family_guess,weight,case,position,animation}, overlay_elements[], transition_in, transition_out, safe_area_ok, visual_quality_1_10, notes}`
- **P3c caption analyser** (Haiku/Gemini) -> `{hook_line, structure[], cta_type, hashtag_count, hashtag_tiers, emoji_density, length_chars, language_mix, mentions[], tone}`
- **P3d voice/delivery profile** (dari transkrip; generik, tanpa identitas) -> `{wpm, register, sentence_len, filler_words, opening_formula, closing_formula}`

**Step 4 — Recipe synthesis**
- **P4 recipe** (Claude via MCP, fallback Opus API; input: agregat P3a-d per source) -> `content_recipes.params: {schema_version, format_mix, duration_p50_p90, hook_patterns:[{pattern,freq,generalised_example}], scene_templates[], overlay_style, caption_template, cta_library[], music_profile, voice_profile, do_not[], evidence:{media_ids[],counts}}`

**Step 6 — Agent generate**
- **P6a compose** (Sonnet default / Opus premium / Haiku sub-task; input: profil agent + fakta listing + ringkasan P6b + `recipe.params` + geo; guardrail: hanya fakta listing, tanpa harga karangan) -> `{script:[{scene_no,t,voiceover,on_screen_text,shot_instruction,asset_ref}], caption:{id,en?}, hashtags[], thumbnail_text, cta, tts_text, edit_plan}`
- **P6b upload vision** (GPT-6 per asset) -> `{room, quality_1_10, best_use, orientation, issues[], suggested_crop, staging_candidate}`
- **P6c 3D/staging job** (async, model image/video — bukan gpt-6) -> `{before, after, prompt_used, params}`

**Step 7 — Editorial render**
- **P7 render brief** per scene (Gemini-video/Veo atau Kling) -> `{prompt, duration, aspect, motion, seed}`
- Opsional **judge** sebelum rilis -> `{score_1_10, reasons[], blocking_issues[]}`

**Step 9 — Level-2 relearn**
- **P9 relearn** (Claude MCP design-time; input: recipe vN, generations 👎 + inputs, exemplar 👍, analisis failure-frame GPT-6 dengan `feedback_at > relearn_flagged_at`) -> `{diff_summary, params_v2, changed_keys[], rationale, expected_lift}` -> insert resep v2 (draft, level 2, parent_id) lalu `admin_activate_recipe` + `admin_ack_relearn`.

Prioritas penulisan: P3a, P3c, P4 dulu (cukup untuk dry-run 5 video, biaya hanya Gemini), lalu P6a/P6b saat Step 6 dibangun, P3b/P7/P9 terakhir.
